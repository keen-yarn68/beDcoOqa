# 项目简介

## 核心功能
- 支持图片、视频及摄像头进行检测
- 可选择不同检测模型
- 界面实时显示目标位置、目标总数、置信度等信息
- 支持批量检测并直接查看所有检测结果
- 支持检测结果保存
- 支持自定义置信度和IOU阈值
- 可选择显示标签和原图
- 提供三种识别方式：单张图片或图片文件夹、视频文件、本地摄像头

## 适用场景
- 车道线检测与实例分割分析
- 交通监控系统开发
- 智能驾驶研究
- 道路安全分析
- 计算机视觉教学演示

## 技术特点
- 基于YOLOv8深度学习框架
- 使用Pycharm+Anaconda或VSCode+Anaconda开发环境
- 依赖Python3.9、opencv-python、PyQt5、ultralytics、torch1.9等技术栈
- 包含1400张标注数据集，专注于['lane']一类目标检测
- 提供完整源码、训练好的模型及运行教程
